# Calculator project

## Requirements
- Build a basic calculator.
- Use black colour for the background and blue colour for the calculator.

## Project overview
A dependency-free browser calculator. Open index.html in a modern browser.

## Features
- Addition, subtraction, multiplication, and division
- Decimal input, sign toggle, percentage, clear, backspace, and equals
- Keyboard support for digits, operators, decimal point, Enter, Escape, and Backspace
- Responsive layout, visible keyboard focus, and an accessible live display

## Files
- index.html contains the page, styles, and calculator logic.

## Implementation notes
- Keep the app self-contained and dependency-free.
- Preserve the black background and blue calculator appearance when editing.
- Keep button labels and accessible names in sync when changing controls.
- Division by zero displays Error; AC resets the calculator.
